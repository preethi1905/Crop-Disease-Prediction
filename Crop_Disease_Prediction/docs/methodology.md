# Methodology

## 1. Data Collection

- Paddy Disease Dataset
- 1850 labeled images
- 6 disease classes

## 2. Image Preprocessing

- Image resizing (100 × 100)
- RGB conversion
- Normalization

## 3. Feature Extraction

### Color Features
- Mean RGB values
- Standard deviation

### Texture Features
- GLCM
- Contrast
- Homogeneity
- Energy
- Correlation

### Shape Features
- Contour detection
- Area
- Perimeter

## 4. Data Splitting

- Training Data: 80%
- Testing Data: 20%

## 5. Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- SVM
- KNN
- Naive Bayes
- XGBoost

## 6. Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## 7. Final Result

Best Model: XGBoost

Accuracy: 86.4%
