# Crop Disease Prediction Using Machine Learning

## Project Overview

This project focuses on the early detection and classification of paddy crop diseases using Machine Learning techniques. The system analyzes leaf images and predicts disease categories to support farmers in timely crop management and yield improvement.

## Dataset

- Paddy Disease Dataset
- 1850 labeled leaf images
- 6 Classes:
  - Bacterial Leaf Blight
  - Brown Spot
  - Healthy Leaf
  - Leaf Blast
  - Others
  - Tungro
